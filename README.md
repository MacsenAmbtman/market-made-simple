# Market Made Simple

[OVERVIEW]

Build a clean, highly visual, and simple financial education app called "Stockify" (or "MarketBites"). The goal of the app is to break down stock market investing into bite-sized, non-intimidating lessons for complete beginners.

[KEY PAGES & NAVIGATION]

1. Landing Page: 

   - Modern, friendly Hero section: "Learn to invest without the confusing jargon."

   - A primary CTA button: "Start Free Lesson 1"

   - Feature highlights: Bite-sized modules, real-world examples, and a fake "Paper Simulator" preview.

2. Interactive Dashboard (App Interface):

   - Sidebar navigation: "Learn", "Paper Simulator", "Glossary", "My Progress".

   - Progress bar tracking lessons completed.

   - Lesson Modules Grid (e.g., "What is a Stock?", "Compound Interest Magic", "Index Funds vs. Single Stocks", "How to Buy Your First Share").

3. Sample Lesson Page:

   - Card layout with short, simple text paragraphs.

   - Visual stat counters, progress bar at the top, and interactive multiple-choice quiz questions at the end of the lesson.

4. Paper Simulator Page (Mock Trading):

   - A simple interface giving the user $10,000 in virtual cash.

   - Quick "Buy" and "Sell" buttons for 3-4 sample mock stocks (e.g., Apple, Tesla, S&P 500 Index).

   - A basic line chart showing portfolio balance over time.

[VISUAL STYLE & THEME]

- Color Palette: Deep Slate/Dark Navy background (#0F172A), vibrant mint green accents (#10B981) for money/growth themes, and clean white text.

- Clean, modern, accessible typography with subtle rounded cards and shadow effects using Tailwind CSS.

[TECHNICAL & DATA]

- React, TypeScript, and Tailwind CSS.

- Responsive design for mobile screens and desktop.

[FIRST TASK]

Generate the full layout, landing page, interactive learning dashboard shell, and the sample paper simulator page.
